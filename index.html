The Challenge

Investigate hemodynamic outcome variability in ICU patients using the MIMIC-IV clinical database. Identify significant predictors of MAP trends and ICU outcomes to support clinical decision-making.

What I Did

Extracted and queried 50,000+ ICU patient records via SQL. Applied logistic regression and mixed-effects models. Built an interactive R Shiny dashboard with ggplot2 visualizations for dynamic exploration by clinical stakeholders.

Key Finding
